# Бүгд Найрамдах Солонгос Улс — танилцуулга сайт

## Файлууд
- `index.html` — сайтын бүтэц, Монгол текст
- `style.css` — улаан/алтлаг загвар, утас болон компьютерийн responsive дизайн
- `script.js` — гар утасны цэс болон хуудасны он

## Өөрчлөх
`index.html` доторх жишээ текст, овгийн түүх, нэрсийг өөрийн бодит мэдээллээр солино. Ургийн модны жишээ картуудыг мөн өөрчилж болно.

## GitHub Pages дээр нийтлэх
1. GitHub-д нэвтэрч `korea-clan` нэртэй шинэ Public repository үүсгэнэ.
2. Энэ хавтас доторх гурван файлыг repository-ийн үндсэн (root) хэсэгт upload хийнэ.
3. Repository → **Settings** → **Pages** руу орно.
4. **Build and deployment** хэсэгт Source: **Deploy from a branch** сонгоно.
5. Branch: **main**, folder: **/(root)** сонгоод **Save** дарна.
6. Хэдэн минутын дараа `https://ТАНЫ-USERNAME.github.io/korea-clan/` хаягаар нээгдэнэ.

Google Fonts ашигласан тул фонтуудыг ачаалахад интернэт хэрэгтэй. Бусад үндсэн дизайн, цэс нь тусдаа framework шаардлагагүй.
